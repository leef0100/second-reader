# Second Reader

**For research use only. Not for diagnostic use.**

AI "second reader" for medical imaging — a research prototype that helps clinicians catch missed findings on chest X-rays (pneumothorax, pleural effusion, pulmonary nodule/mass). It supports the clinician's decision; it never makes it.

Full setup instructions arrive in Phase 5. Until then: `make sync && make check`, `scripts/dev_up.sh`.

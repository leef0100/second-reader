# Split manifests

Generated by `secondreader datasets split` (Phase 3). CSVs are git-ignored (they
enumerate image paths); only `manifest.sha256` files are committed, and the
external-test hash is recorded in `DECISIONS.md` at lock time.

Label values: `1`, `0`, `-1` (uncertain → masked), empty (unknown).
